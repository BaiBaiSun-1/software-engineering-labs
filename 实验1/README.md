# 实验1：软件工具的使用

## 实验目标

1. 完成 Git 与 GitHub 的基本配置。
2. 从零实现并运行一个简单的签到系统。
3. 使用 Git 记录开发过程并推送到 GitHub。
4. 使用 Codex 完成最小程序体验和签到系统功能扩展。
5. 整理运行截图、提交记录、AI 使用记录和实验总结。

## 技术选型

- Python
- Flask
- SQLite
- HTML / CSS
- Git + GitHub
- Codex

## 计划目录

```text
实验1/
├─ attendance-system/   # 签到系统
├─ hello-codex/         # AI 最小程序
├─ docs/                # 截图与过程证据
└─ report/              # 实验报告
```

## 签到系统计划功能

- 创建签到活动
- 学生输入姓名和学号签到
- 自动记录签到时间
- 阻止同一学号重复签到
- 查看和查询签到记录
- 导出签到记录

> 本实验按要求使用 GitHub 替代 Gitee，使用 Codex 作为 AI 编程 Agent。
