# 实验一过程记录

## 工具与替换说明

课程任务允许等价替换。本实验使用 GitHub 替代 Gitee，使用当前 Codex 会话作为 AI 编程 Agent。代码、文档、测试与报告由 Codex 协助完成；关键结果通过本地运行、自动化测试和 Git 提交历史验证。

## AI 最小程序

给 Codex 的工作要求由任务文件转写为：“用 Python 编写一个最小命令行程序，输出 `Hello, AI 编程！`；本地运行验证后做一次小幅改进。”

Codex 首先生成只包含一次输出的 `hello.py`，本地运行成功，对应提交 `7f13461`。随后将程序改为支持可选 `--name` 参数，运行默认输出和 `--name 同学` 输出，结果分别为 `Hello, AI 编程！` 和 `你好，同学！Hello, AI 编程！`，对应提交 `61a7a78`。

## 签到系统的 AI 使用范围

基础需求：创建活动、填写虚构学号和姓名、保存签到时间、查看记录。Codex 编写 Flask 路由、SQLite 表结构、页面模板和样式；本地冒烟检查得到 `GET / 200`、创建活动后的详情页 `200`、首次签到后详情页 `200`，对应提交 `4c75d23`。

扩展需求：“防止同一学号在同一活动重复签到，并支持查询和导出签到记录。”Codex 增加数据库唯一索引、大小写归一化、重复提示、搜索和 CSV 导出。人工复核的重点是：重复提交后总人数仍为 1；查询只返回匹配记录；导出文件含中文表头和 UTF-8 BOM；无效学号及不存在的活动得到明确处理。运行 `python -m unittest discover -s tests -v`，2 个测试通过，对应提交 `00430ed`。

## 实际排查记录

1. 初次测试时，Windows 的 Python 环境缺少 `Asia/Shanghai` 时区数据库，创建活动报 `ZoneInfoNotFoundError`。改为读取本机时区 `datetime.now().astimezone()`，确认系统时区为中国标准时间 UTC+08:00 后重新运行，基础流程通过。
2. 初次 Git 提交因未配置作者署名被拒绝。仅为本仓库设置 GitHub 用户名和 `noreply` 提交邮箱，避免在公开提交中暴露个人邮箱，之后提交成功。
3. 首次用 PowerShell 查看中文输出出现终端编码显示异常。将本次运行的 `PYTHONIOENCODING` 设置为 `utf-8` 后，最小程序输出正常。
